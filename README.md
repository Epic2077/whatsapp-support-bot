# WhatsApp Support Bot

ربات پشتیبانی فارسی برای واتساپ با ثبت سرنخ، دانش‌نامه وب، سه ارائه‌دهنده هوش مصنوعی و ارسال خلاصه مکالمه به گروه پشتیبانی.

## راه‌اندازی

1. Node.js 20 یا جدیدتر نصب کنید.
2. `npm install` را اجرا کنید.
3. `.env.example` را به `.env` کپی و رمز مدیر، کلیدها، URL ارائه‌دهنده‌ها و `SUPPORT_GROUP_JID` را تنظیم کنید.
4. برای ساخت دانش‌نامه، `KNOWLEDGE_URLS` را با URL مادر یا چند URL شروع پر کرده و `npm run scrape` را اجرا کنید. خزنده لینک‌های داخلی همان دامنه را تا عمق و تعداد تنظیم‌شده دنبال می‌کند.
5. `npm start` را اجرا کنید و QR نمایش‌داده‌شده را با WhatsApp > Linked devices اسکن کنید.

## امکانات

- اولین پیام نام و پیام بعدی شماره تلفن را می‌گیرد.
- پاسخ‌ها با دانش‌نامه سایت و ارائه‌دهنده فعال تولید می‌شوند و پیش‌فرض فارسی هستند.
- خزنده از URL مادر شروع می‌کند، لینک‌های داخلی HTTP/HTTPS همان دامنه را کشف می‌کند، صفحات تکراری و anchorها را حذف می‌کند و متن صفحات را به قطعه‌های قابل جست‌وجو تقسیم می‌کند.
- هنگام سؤال، قطعه‌های مرتبط از میان تمام صفحات crawled با تطبیق واژه‌های فارسی/عربی انتخاب می‌شوند؛ فقط همان منابع مرتبط به مدل داده می‌شوند.
- ارائه‌دهنده‌ها: `liria`، `deepseek` و `gapgpt`. هر سه با API سازگار با OpenAI پیکربندی می‌شوند؛ URL دقیق سرویس‌ها را از مستندات همان سرویس در `.env` وارد کنید.
- مدیر با `/admin <password> help` وارد بخش مدیریت می‌شود. دستورات `stats`، `leads`، `provider` و `broadcast` در دسترس هستند.
- پس از `CHAT_TIMEOUT_MINUTES` دقیقه بی‌پیامی، خلاصه آخرین پیام‌ها همراه با نام، تلفن و شناسه واتساپ به گروه پشتیبانی ارسال می‌شود.

## نکات امنیتی و عملیاتی

- رمز مدیر و کلیدهای API را commit نکنید.
- این نسخه اطلاعات را در `data/store.json` نگه می‌دارد؛ برای حجم بالا یا اجرای چند نمونه، آن را با PostgreSQL/Redis جایگزین کنید.
- قبل از استفاده واقعی، رضایت کاربر برای ثبت شماره، سیاست نگهداری داده و دسترسی اعضای گروه پشتیبانی را مشخص کنید.
- نسخه فعلی پیام‌های گروه‌ها را پردازش نمی‌کند؛ گروه فقط مقصد اعلان سرنخ است.
- تنظیمات crawl شامل `CRAWL_MAX_DEPTH`، `CRAWL_MAX_PAGES`، `KNOWLEDGE_CHUNK_CHARS` و `CRAWL_REQUEST_TIMEOUT_MS` است.
